# Product

## Register

product

## Users

Players at a desktop who want a fast, replayable bullet-hell run with a clear launch point and a strong sense of place.

## Product Purpose

Void Strike is a native desktop bullet-hell game. The interface should get players into a run quickly while making the world, progression, and player ship feel worth returning to.

## Brand Personality

Energetic, tactical, mysterious. The UI should feel like a capable flight system with enough spectacle to make launching a run feel exciting.

## Anti-references

Avoid a lifeless monochrome menu stack, generic dashboard patterns, decorative clutter that competes with Play, and neon color used without hierarchy or meaning.

## Design Principles

- Make the next action obvious without flattening the game world into a form.
- Use spatial composition to make the player ship and mission feel present before the run begins.
- Treat color as a signal system: primary action, system status, and atmosphere should have distinct roles.
- Keep menu interactions fast, keyboard-friendly, and predictable.
- Let spectacle live in the background and motion while preserving a calm, legible control surface.

## Accessibility & Inclusion

Aim for WCAG AA contrast for interface text and controls, preserve visible keyboard focus, never rely on color alone to communicate action state, and reduce decorative motion when the operating system requests reduced motion.
